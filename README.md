# blackjack-sdl
Blackjack in C using SDL3.
Uses 5-card Charlie rule (player wins on 5 cards).
I definitely need to work more on my game architecturing skills but regardless I learnt a good amount creating this and am fairly happy with the final result.
# INSTALLATION
Requires SDL3, SDL_ttf, FreeType and Harfbuzz as dependencies. From the blackjack-sdl folder run the following.
```
mkdir build
cd build
cmake ..
make
./main
```
